AI-Based Object Detection

Project Description

This project detects objects in uploaded images using YOLO (You Only Look Once) and displays the detected objects with bounding boxes and confidence scores.

Technologies Used

- Python
- YOLOv8
- OpenCV
- Gradio
- Google Colab

Features

- Upload an image
- Detect multiple objects
- Display bounding boxes
- Show detected object names and confidence scores

How to Run

1. Open the Google Colab notebook.
2. Install the required libraries.
3. Run all code cells.
4. Upload an image.
5. Click Detect Objects to view the result.
